# Безопасность публикации

Исходники опубликованы отдельным снимком Android-клиента. Серверные конфигурации, токены, пользовательские базы, журналы и закрытые ключи подписи не входят в репозиторий. Не добавляйте их в issues или pull requests.

Сессии создаются после входа конкретного пользователя, а на Android сохраняются через Keystore. Адрес сервиса в готовом APK является публичным адресом API, а не секретом. Проверка прав должна выполняться сервером.

Версия 0.2.3 остаётся предварительной debug-сборкой. Полноценная release-подпись, автоматические обновления и отдельное управление сессиями устройств ещё не реализованы.

Зависимости сохранены от текущей работающей версии. На момент публикации `npm audit` сообщает 5 проблем (3 high, 2 moderate), включая инструменты разработки Vite/esbuild и транзитивные зависимости. Проверка на секреты не заменяет аудит приложения. Обновление зависимостей требует отдельной проверки совместимости; не открывайте dev-сервер для посторонних.
